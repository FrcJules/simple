# Launcher Android

Kotlin + Jetpack Compose. Se déclare comme application d'accueil (HOME). Ouvrir ce dossier dans Android Studio (JDK 17), ou :

```bash
gradle :app:lintDebug :app:testDebugUnitTest :app:assembleDebug
```
